# docs/projeto — documentos de origem

Os documentos que definiram o projeto antes de existir código. Ficam aqui como
fonte, não como especificação viva: quando um deles divergir do que está
implementado, `docs/DECISIONS.md` vale.

| Arquivo | Conteúdo |
|---|---|
| `manual-tecnico.md` | arquitetura completa, BOM, algoritmos, plataforma de gestão, proteção patrimonial, restrições jurídicas |
| `prompts-claude-code.md` | roteiro de construção do software em 13 etapas, com tabela de dependências |
| `guia-montagem-integracao.md` | montagem física e integração hardware-software, com checkpoints e erros comuns |

Os documentos comercial, institucional e de estratégia do projeto ficam fora
deste repositório — aqui é software.
