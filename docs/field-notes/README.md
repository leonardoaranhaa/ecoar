# field-notes/ — notas de campo

Uma nota por sessão de gravação ou de teste em campo. O áudio bruto **não** é
versionado (ver `.gitignore`); fica no armazenamento do projeto, referenciado
aqui pelo identificador.

Modelo de nota:

```markdown
# 2026-MM-DD — Local

- Ponto: (endereço, coordenadas)
- Horário e duração:
- Equipamento: (celular / array / qual)
- Condições: (trânsito, clima, obra próxima, evento na cidade)
- Amostras coletadas: N arquivos, identificadores
- Rotulagem: quem rotulou, quantas de cada classe
- O que isso mudou no projeto:
```

A última linha é a que importa. Gravação que não mudou nenhuma decisão devia ter
sido mais curta.
